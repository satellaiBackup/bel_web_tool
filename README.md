# 本地静态站点服务

这是一个使用 Go 编写的极简静态文件服务器，它会随机选择本机空闲端口，自动打开浏览器并载入本目录下的 `index.html`。非常适合在调试蓝牙调试助手页面或围栏编辑器时，避免浏览器的 `file://` 安全限制。

## 环境要求

- 安装 [Go](https://go.dev/dl/)（推荐 1.21 及以上版本）
- Windows、macOS 或主流 Linux 发行版均可运行

## 使用方式

### 直接运行（开发场景）

```powershell
# 在仓库根目录执行
go run .
```

程序启动后会：

1. 自动挑选一个空闲端口（例如 `http://127.0.0.1:54321`）。
2. 自动打开默认浏览器并访问 `index.html`。
3. 在终端中打印访问日志，方便调试。

### 构建独立可执行文件

```powershell
# 编译为当前平台的可执行文件
go build -o webserver.exe

# 运行编译后的程序
./webserver.exe
```

> Windows 下运行 `webserver.exe` 时同样会自动唤起默认浏览器。

## 常见问题

- **浏览器未自动打开**：终端会提示访问地址，自行复制到浏览器即可。
- **端口被防火墙拦截**：程序使用环回地址 `127.0.0.1`，通常不会被防火墙阻止；若被提示，允许本地访问即可。
- **地图仍无法加载**：请确认已通过该服务器访问页面，而不是直接双击 `index.html`。
